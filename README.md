# AirTextPad ✈️📝
Wireless cross-device text sync & snippet manager via local network.

## 🚀 Quick Start
1. Download `AirTextPadSetup.exe` from [Releases](../../releases/latest)
2. Install and launch
3. Scan QR code with phone to sync instantly

## 💻 Dev Setup
```bash
npm install
npm start        # Dev mode
npm run dist     # Build EXE
