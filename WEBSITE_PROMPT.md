# Website Prompt for Air Drop Text

Create a modern, responsive website for a Windows desktop app called **Air Drop Text**.

The website should be simple, trustworthy, and built for beta users who want to download the app. The tone should be clear, beginner-friendly, and practical.

## Product

Air Drop Text is a local Wi-Fi text sharing and notes app. It lets users quickly send temporary text, links, and saved snippets between their Windows computer and phone on the same Wi-Fi network.

## Website Goals

- Help users understand what the app does in 10 seconds.
- Provide a clear Windows download button.
- Explain that the app works locally on the user's Wi-Fi.
- Show Free Beta and future Pro plan information.
- Provide support, privacy, and changelog sections.
- Build trust before subscriptions are added.

## Pages or Sections

1. Hero
   - Headline: "Air Drop Text"
   - Subheadline: "Share text, links, and notes between your Windows PC and phone over local Wi-Fi."
   - Primary button: "Download for Windows"
   - Secondary button: "View setup guide"
   - Include a real app screenshot or a clean product mockup.

2. How It Works
   - Step 1: Open Air Drop Text on Windows.
   - Step 2: Scan the QR code with your phone.
   - Step 3: Type or paste text and it syncs instantly.

3. Features
   - Live text sync
   - Saved snippets library
   - QR code connection
   - Local Wi-Fi sharing
   - Passcode protection
   - Dark mode
   - Export and import notes

4. Pricing
   - Free Beta
     - Local live sync
     - Saved notes
     - QR pairing
     - Export/import
   - Pro, coming later
     - License key activation
     - Priority updates
     - Advanced backup options
     - More customization

5. Download
   - Windows installer download button
   - Version number
   - Release date
   - Short install instructions
   - Note: "Windows may show a warning for early beta builds until code signing is added."

6. Privacy
   - "Your notes and live text stay on your device/local network."
   - "The app does not require cloud sync for local sharing."
   - "Future license activation may contact a license server only to verify subscription status."

7. Support
   - Email support
   - WhatsApp/contact option if desired
   - FAQ
   - Troubleshooting: Windows Firewall, Private Wi-Fi network, phone and PC on same network

8. Changelog
   - Version 1.0.0
   - Initial beta release
   - Live sync, notes library, passcode protection, dark mode, export/import

## Design Direction

- Clean SaaS/product style, not too decorative.
- Use a light and dark theme preview.
- Use blue as the primary brand color.
- Use app screenshots prominently.
- Make the download button visible in the first screen.
- Keep cards simple with 8px border radius.
- Mobile responsive.

## Copy Notes

Use honest beta wording. Do not overpromise cloud sync or enterprise security. Make it clear that the product is local-first and that paid licensing is planned for later.
