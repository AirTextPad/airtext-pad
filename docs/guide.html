Quick setup guide

Get connected.

Set up AirTextPad between your Windows PC and phone in a few steps.

01

Download and install

Get the latest Windows installer from the official Releases page. Run the installer and open AirTextPad.

02

Connect to one network

Connect your Windows PC and phone to the same Wi-Fi network or phone hotspot. A guest network or client isolation setting may prevent devices from seeing each other.

03

Scan the QR code

Use your phone camera to scan the QR code displayed in the Windows app. Open the companion page in your phone browser.

04

Enter the passcode if asked

If the host has enabled passcode protection, enter the passcode configured in the desktop app. Only connect devices and networks you trust.

05

Share text and notes

Use the live text area for quick transfers and the notes library for reusable snippets. Keep the Windows host app running while using the phone companion.

06

Disconnect safely

When finished, close the phone companion page and stop or exit the host app if you no longer need local access.

Troubleshooting: If the phone cannot connect, confirm both devices are on the same Wi-Fi, refresh the QR code, check Windows Firewall permissions for a Private network, and ensure the host app is running. Avoid exposing the local server directly to the public internet.

Still stuck?

Send your Windows version, AirTextPad version and a short description of what happened to airtextpad@gmail.com. Do not include passwords or private text content.
