Get connected in a few steps

From PC to phone, simply.

AirTextPad uses the Windows app as the host and your phone's browser as the companion screen.

01

Install AirTextPad

Download and install the Windows desktop app, then launch it on your PC.

02

Join the same network

Connect your phone and Windows PC to the same Wi-Fi network or phone hotspot.

03

Scan and start syncing

Scan the QR code displayed by AirTextPad. Enter the host passcode if prompted, then share text and notes.

Network and security note: AirTextPad's host is reachable over the local network. Use it only on networks you trust, enable the remote passcode option where appropriate, and do not expose its local server directly to the public internet. A passcode is an access control, not a substitute for network security.

Questions, answered

Good to know.

Is AirTextPad free?

Yes. AirTextPad is offered free to use. The Windows installer is available from the official GitHub Releases page.

Is there an Android or iPhone app?

The phone experience runs in your mobile browser. The Windows desktop app hosts the connection; this is not a separate native Android or iOS app.

Do both devices need the same Wi-Fi?

Yes. Your Windows PC and phone should be connected to the same local network, such as the same Wi-Fi router or a phone hotspot.

Does AirTextPad upload my notes to the cloud?

AirTextPad is designed for direct local-network use and does not require an AirTextPad cloud account. Keep your devices on a trusted network and follow the security guidance above.

What if my phone cannot connect?

Check that both devices are on the same network, scan the current QR code, and check whether Windows Firewall allows AirTextPad on your Private network. If access protection is enabled, enter the host passcode.

Where can I get help or report a problem?

Visit the project repository and open the Issues section to report a bug or request an improvement.
